## 🌟 Overview

Interactive personal portfolio showcasing production-grade ETL data pipelines, agentic AI systems, enterprise backend engineering deliverables, and technical case studies with live interactive demonstrations:

- **Interactive SQL Sandbox:** Live browser terminal executing PostgreSQL CTEs, Medallion Gold aggregations, OCR anomaly detection, and Sentinel QC ATS integrity validation.
- **Dynamic Bento Grid:** Modern dark-mode layout with responsive mouse spotlight cursor tracking and micro-animations.
- **Interactive AI Recruiter Assistant:** Built-in drawer answering recruiter questions and role qualifications in real time.
- **Flagship Projects Showcase:** Deep-dive specs and architecture flows for Sentinel QC, Auto-Analyst ETL, Vendor Invoice Intelligence, and ATS Tailor.
- **Role Persona Switcher:** Instant pivot across *Data & Business Analyst*, *Full-Stack Engineer*, *AI Systems Builder*, and *Technical Support*.
